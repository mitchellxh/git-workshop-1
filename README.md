# Introduction to GitHub

Welcome! This repository is part of a beginner-friendly workshop on using **GitHub** — the platform where developers (and many others!) store, share, and collaborate on projects.

You've landed here because you're working on **Activity 3**. Follow the steps below at your own pace.

---

## Activity 3: Explore, Star, Fork, and Clean Up

### Step 1: Search for This Repository

You found this repo — but let's practice the search feature:

1. Click the **search bar** at the very top of the GitHub page (or press `/` on your keyboard).
2. Type **`git-workshop-1`** and press Enter.
3. You'll see search results across all of GitHub. Look for **`mitchellxh/git-workshop-1`** in the results and click on it.

> **Tip:** You can filter results by clicking **Repositories** on the left sidebar to narrow things down.

---

### Step 2: Star This Repository

"Starring" a repository is like bookmarking it. It helps you find it later and shows the creator that you found their project interesting.

1. Near the top-right of this page, find the **Star** button (next to "Fork" and "Watch").
2. Click **Star**.
3. That's it! You've starred this repo.

**Where do my stars go?**
- Click your **profile picture** (top-right corner) and select **Your stars** to see everything you've starred.

---

### Step 3: Fork This Repository

"Forking" creates your own personal copy of someone else's repository. It lives in your account, and you can make changes without affecting the original.

1. Near the top-right of this page, click the **Fork** button.
2. On the next screen, you can leave everything as-is — just click **Create fork**.
3. GitHub will redirect you to **your fork**. Notice the URL has changed to `github.com/YOUR-USERNAME/git-workshop-1`.

> **What just happened?** You now have your own copy of this entire repository. The original (this one) is called the "upstream" repository.

---

### Step 4: Delete Your Fork

Now let's clean up by deleting the fork you just created. Don't worry — deleting your fork does **not** affect the original repository.

1. Go to **your fork** (it should be at `github.com/YOUR-USERNAME/git-workshop-1`).
2. Click **Settings** (the gear icon tab near the top of the page).
3. Scroll all the way to the bottom to the **Danger Zone** section.
4. Click **Delete this repository**.
5. GitHub will ask you to type the repository name to confirm. Type it in and confirm the deletion.

> **Important:** This only deletes *your copy* (the fork). The original repository here at `mitchellxh/git-workshop-1` is completely unaffected.

---

## You're Done!

Nice work completing Activity 3. Here's a quick recap of what you learned:

| Concept    | What It Does                                              |
|------------|-----------------------------------------------------------|
| **Search** | Find repositories, users, and code across all of GitHub   |
| **Star**   | Bookmark a repository so you can find it later            |
| **Fork**   | Create your own copy of someone else's repository         |
| **Delete** | Remove a repository from your account (only affects yours)|
